  1. Edit — Connect: nodo previo → Section → hijos (el primer hijo = más arriba / izquierda).
  2. Al masterizar el previo, la Section se abre y solo el primer hijo queda available.
  3. El siguiente hijo de la Section se desbloquea al asignar el anterior (o con Connect directo).
  4. Train — clic = allocate → master. Doble clic = completado. Clic derecho = elegir estado. Shift+clic = refund.
